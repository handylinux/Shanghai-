# Шанхай · навигатор (PWA)

Офлайн-приложение для поездки в Шанхай (10 дней, 29.10–7.11). Открывается в браузере телефона и компьютера, поддерживает установку как PWA («На главный экран»).

## ✨ Возможности
- **🛬 Прилёт** — пошаговая инструкция: аэропорт Пудун (PVG), маглев (431 км/ч), пересадки и отель.
- **📅 Дни** — 10 дней подробной программы с распределением локаций по дням.
- **📍 Места** — каталог всех локаций: китайские названия для таксистов (汉字), точные адреса, линии и выходы метро, цены, описания и подборка «Что рядом» (≤ 2.5 км).
- **🗺️ Карта** — интерактивная карта всех точек на базе Leaflet и OpenStreetMap.
- **✓ «Посетил»** — сохранение прогресса поездки локально в браузере (LocalStorage).
- **↗ Внешняя навигация** — быстрый переход к OpenStreetMap и Google Maps в один клик.

## 🚀 Запуск и публикация через GitHub

Проект представляет собой автономное статическое веб-приложение (HTML5 / ES6 / Service Worker) и готов к работе через **GitHub Pages**.

### 1. Автоматический деплой через GitHub Actions
В репозитории настроен workflow `.github/workflows/deploy.yml`. Чтобы активировать:
1. Перейдите в репозитории: **Settings → Pages**.
2. В секции **Build and deployment → Source** выберите **GitHub Actions**.
3. При любом пуше сайт автоматически соберется и опубликуется по адресу:
   ```
   https://handylinux.github.io/Shanghai-/
   ```

### 2. Прямой деплой из ветки (Deploy from a branch)
1. В **Settings → Pages** выберите:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (или текущую рабочую ветку) / `/ (root)`
2. Нажмите **Save**. Сайт будет доступен по адресу:
   ```
   https://handylinux.github.io/Shanghai-/
   ```

## 💻 Локальный запуск
Для работы офлайн-кэша Service Worker приложению требуется `localhost` или `https://`:
```bash
python3 -m http.server 8080
# откройте http://localhost:8080 в браузере
```

## ✏️ Как редактировать данные
Все локации, дни и маршруты находятся в файле **`data.js`** (`window.SH_DATA`). Сборка не требуется: любые изменения в `data.js` сразу отображаются в приложении.

### Добавление фото к месту
1. Поместите изображение в папку `photos/` (например, `photos/bund.jpg`).
2. В объекте локации в `data.js` укажите: `"photo": "bund.jpg"`.
